# Challenge - Amigo Secreto
# Generado por Alvaro Luis Medina Almendares
# Github: ares-md

Aplicación web para agregar nombres de amigos y sortearlos aleatoriamente.

Los nombres debe ingresarlos el administrador del sorteo pues al ejecutar la aplicación se le desplegará una tabla con todas las asignaciones para que las comparta con cada usuario respectivamente. Así evitamos "spoilers" de los resultados para máxima diversión!!

## Funcionalidades
- Máximo 20 amigos
- Ningún amigo se asigna a sí mismo
- Genera todas las parejas con un click
- Muestra un popup con la tabla resumen

## Tecnologías
- HTML5, CSS3, JavaScript

## Uso
1. Abrir `index.html` en navegador o usar GitHub Pages
2. Agregar nombres de amigos. Deben haber almenos 2 nombres para que la aplicación funcione, de lo contrario lanzará una alerta con mensaje de error.
3. Para ejecutar Hacer click en "Sortear amigo"
4. Una vez que se ejecute el sorteo, aparecerá la tabla con los resultados, al cerrar dicha tabla se reiniciará la aplicación automaticamente.
